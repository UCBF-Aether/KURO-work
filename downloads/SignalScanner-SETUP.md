# Signal Scanner — Setup

A live radio scanner for Android. It shows you what is really in the
air around you — only live measurements from your phone's own radios.
Nothing from databases. Works fully offline.

## What you need

- An Android phone
- The Signal Scanner APK (from KUROworks)

## Steps

1. Download the APK.
2. Open it. Android will ask if you want to install from this source —
   say yes. (It is not from the Play Store. That is the point.)
3. Open Signal Scanner. Grant Location permission when asked — Android
   requires it for Wi-Fi and Bluetooth scanning. The app does not track
   you; the permission is how Android gates the radios.
4. That is it. The readings start live.

## What you see

- Wi-Fi, cellular, GNSS, Bluetooth, NFC, UWB — live, right now
- Signal strength, frequencies, and what your phone can actually hear
- Nothing is looked up from a database. If your phone cannot measure
  it live, it does not show it.

## Updates

Tap "Check for updates" inside the app. Every app we build has one.

## If it does not work

- No readings: check the Location permission is granted, and that the
  radio (Wi-Fi, Bluetooth) is switched on.
- Install blocked: allow installs from your browser / file manager in
  Android Settings, then open the APK again.
