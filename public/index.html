The honesty contract

REALEvery node and edge below comes from the Virtual Fly Brain query API against the FlyWire FAFB v783 Drosophila connectome (class-aggregated connectivity, edge weight = total synapse count). No neuron, synapse, or connection was invented. Data frozen Oct 2026.

TOYThe dynamics are a toy: normalized spread-of-activation with a 0.15 firing threshold. No biophysics — no leak, no inhibition, no neurotransmitter signs, no timing. It answers one question: given the real wiring and a stimulus at the sensory layer, which named populations light up, in what order?

MODELEDThe word→circuit mapping is a hand-built keyword lexicon — my modeling choice, not biology. The fly never saw your word; the circuit fired because I mapped it there.

FICTIONThe one-liner "fly voice" is a narrative gloss. Flies do not have feelings we can access. The behavior line is textbook biology for the identified terminal circuit, stated as known biology.

GAPSDocumented, not hidden: the sweet-sensing gustatory receptor neuron's forward link is not indexed in the VFB database, so the sugar tab shows the real motor-backward chain (SEZ/premotor → proboscis motor neuron) injected at the pre-motor layer. The missing link is recorded in the build log, not faked.
